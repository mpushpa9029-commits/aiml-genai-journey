# Day 7 - Structured Prompting

## What is Structured Prompting?

Structured prompting means organizing a prompt into clear sections so the AI understands the task better.

## Prompt Structure

- Role
- Task
- Context
- Constraints
- Output Format

## Example

Role: AI Mentor

Task: Explain Machine Learning

Context: I am a beginner

Constraints:
- Use simple English
- Give 5 points
- Give one example

Output Format: Bullet points

## Key Point

A structured prompt makes the instructions clear and helps produce a more controlled response.
