# Day 4 - Prompting Techniques

## Zero-shot Prompting
Giving a task without any examples.

## One-shot Prompting
Giving one example before the actual task.

## Few-shot Prompting
Giving multiple examples before the actual task.

## Memory Trick
Zero = 0 examples
One = 1 example
Few = Multiple examples

## Key Point
Examples help guide the AI toward the desired pattern and output style.
