# Day 3 - Prompt Engineering Basics

## What is Prompt Engineering?
Prompt Engineering means writing clear instructions for AI to get better and useful responses.

## Prompt Structure
A good prompt can contain:
- Role
- Task
- Context
- Output Format

## Role
Defines who the AI should act as.

Example:
Python Mentor

## Task
Tells the AI what to do.

Example:
Explain Python functions.

## Context
Provides background information.

Example:
I am a beginner.

## Output Format
Specifies how the answer should be presented.

Example:
JSON

## Few-Shot Prompting
Few-shot prompting means giving the AI a few examples before asking a new question.

Example:
Question: What is Python?
Answer: Python is a programming language.

Question: What is AI?
Answer: AI enables machines to perform intelligent tasks.

Then ask:
Question: What is Machine Learning?
