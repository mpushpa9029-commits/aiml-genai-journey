# Day 11 - JSON Prompting and Structured Output

## JSON Prompting

JSON prompting means asking an AI model to return information in a structured JSON format.

## Example Structure

{
    "definition": "...",
    "key_points": [],
    "example": "..."
}

## Why Use Structured Output?

- Easy for Python programs to process.
- Keeps information organized.
- Makes AI output predictable.
- Useful in real-world LLM applications and APIs.

## Important

JSON is a data format.

A Python dictionary can be converted into JSON using the `json` module.
