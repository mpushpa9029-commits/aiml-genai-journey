# Day 10 - Prompt Templates and Variables

## Prompt Template

A prompt template is a reusable prompt structure with variables.

## Variables

Variables allow us to change specific parts of a prompt without rewriting the entire prompt.

Example:

Explain {topic} at {level} level.

Here:
- topic = Python Functions
- level = Beginner

## Why Use Prompt Templates?

- Reuse the same prompt structure.
- Reduce repeated code.
- Easily handle different inputs.
- Useful for building LLM applications.

## Key Point

Template = Fixed prompt structure + Dynamic variables.
