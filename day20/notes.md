# Day 20 - Prompt Chaining with Data Flow

## What is Prompt Chaining?

Prompt chaining means dividing a complex task into multiple smaller steps.

The output from one step can be used as the input for the next step.

## Basic Flow

Topic → Summary → Questions → Answers

## Example

Step 1:
Generate a summary of Machine Learning.

Step 2:
Create interview questions using the summary.

Step 3:
Generate answers for the questions.

## Why Use Prompt Chaining?

- Breaks complex tasks into smaller steps.
- Makes workflows easier to understand.
- Allows outputs to flow between steps.
- Makes AI workflows more organized.
- Useful for building multi-step AI applications.
