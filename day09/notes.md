# Day 9 - System Prompt vs User Prompt

## System Prompt

A system prompt defines how the AI should behave and what rules it should follow.

Example:
"You are a Python Mentor. Explain concepts in simple language."

## User Prompt

A user prompt contains the actual question or task given by the user.

Example:
"Explain Python functions to a beginner."

## Difference

System Prompt → Defines AI behavior and instructions.

User Prompt → Defines the user's request or task.

## Simple Memory

System = HOW AI SHOULD BEHAVE

User = WHAT USER WANTS
